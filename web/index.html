xlc — an optimizing compiler for Excel

drop a workbook. it is parsed, recomputed, and audited on this machine — nothing is uploaded, there is no server.

drop an .xlsx here or click to choose a file

the receipt re-derives every verifiable formula cell and bit-compares against the value Excel itself cached in the file. policy: bit-identical, 1 ULP, or 15 significant decimal digits. exclusions are always listed, never hidden.
